What is a skill?

A small, sharp instruction your agent runs the same way every time: connecting ClickUp, validating a project folder, writing a daily brief.

What is a playbook?

A curated sequence of skills for an end-to-end workflow. Pipelines hand off in one direction; fan-outs branch one shared input into several outputs.

Why it compounds

Every skill lives in one reviewed repository. Tuning one step improves every workflow that runs through it.

Skills

Grouped by when you reach for them. Every skill is invoked explicitly with its $dia- command.

04

Data Analysis

Scaffold analysis workspaces, profile CSV or Excel datasets, map KPIs, and answer one file with read-only SQL.

production

$dia-new-data-analysis-workspace

Scaffold a fresh local data-analysis workspace with raw inputs, numbered pipeline scripts, dashboard-ready output, and a home for meeting transcripts.

 testing

$dia-analyze-local-data

Answer ad hoc questions about one CSV or Excel file inside a data-analysis workspace with a read-only DuckDB view under scratch/analysis.

 testing

$dia-kpi-data-mapping

Validate a confirmed KPI artifact against one named dataset and draft a declarative mapping report naming required fields, calculations to build, and data gaps.

 testing

$dia-dashboard-mockup

Render a UCSD-branded HTML dashboard mockup with mock data and explicit data-gap panels from one KPI data mapping report.

 testing

$dia-dataset-profile

Profile one CSV or Excel file with fields, distributions, missingness, candidate keys, anomalies, and suggested metrics or KPIs.

Documentation

testing

$dia-data-model-intake

Extract deterministic facts from one Oracle BI Publisher data model into model-facts.yaml.

 testing

$dia-data-model-profiler

 testing

$dia-data-model-docs

Draft analyst-facing documents, including a data dictionary and business-questions catalog, from one confirmed model-facts.yaml.
