What is a skill?

A small, sharp instruction your agent runs the same way every time: connecting ClickUp, validating a project folder, writing a daily brief.

What is a playbook?

A curated sequence of skills for an end-to-end workflow. Each skill's output becomes the next skill's input.

Why it compounds

Every skill lives in one reviewed repository. Tuning one step improves every workflow that runs through it.

Skills

Grouped by when you reach for them. Every skill is invoked explicitly with its $dia- command.

01

Connect & Setup

One-time connections. Everything else depends on this.

Start with $dia-clickup-mcp-setup
production

$dia-clickup-mcp-setup

Connect TritonAI Harness to ClickUp through official OAuth and verify Workspace access.

 testing

$dia-setup-project-folder

Create or validate a business-insights project folder connected to ClickUp resources.

Meeting Workflow

Start with $dia-transcript-to-process-map
testing

$dia-transcript-to-meeting-notes

Turn a Zoom transcript into detailed local meeting notes, with no ClickUp writes.

 testing

$dia-transcript-to-requirements

Turn a business-owner requirements conversation into a structured requirements document.

 testing

$dia-transcript-to-process-map

Save the transcript, outline the discussed process and its current-state timing for your confirmation, then render the approved map as a diagram.

 testing

Publish one transcript's meeting notes to Project Hub and create the approved ClickUp tasks.
