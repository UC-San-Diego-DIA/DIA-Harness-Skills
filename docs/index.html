What is a skill?

A small, sharp instruction your agent runs the same way every time: connecting ClickUp, validating a project folder, writing a daily brief.

What is a playbook?

A curated sequence of skills for an end-to-end workflow. Each skill's output becomes the next skill's input.

Why it compounds

Every skill lives in one reviewed repository. Tuning one step improves every workflow that runs through it.

Skills

Grouped by when you reach for them. Every skill is invoked explicitly with its $dia- command.

01

Connect & Setup

One-time connections and project scaffolding. Everything else depends on this.

Start with $dia-clickup-mcp-setup

$dia-clickup-mcp-setup

Connect TritonAI Harness to ClickUp through official OAuth and verify Workspace access.

$dia-setup-project-folder

Create or validate a business-insights project folder connected to ClickUp resources.

02

Meeting Workflow

From a raw transcript to published notes and approved tasks.

Start with $dia-process-meeting-transcript

$dia-transcript-to-meeting-notes

Turn a Zoom transcript into detailed local meeting notes, with no ClickUp writes.

$dia-transcript-to-requirements

Turn a business-owner requirements conversation into a structured requirements document.

$dia-transcript-to-process-map

Save the transcript, create meeting notes, and render the discussed process as a diagram.

$dia-process-meeting-transcript

Draft the Project Hub note, then create only the ClickUp tasks the user approves.

03

Daily Rituals

Short, repeatable routines that keep the day honest.

$dia-start-my-day

Rank one to three priorities from ClickUp and Outlook, with an HTML brief and approved follow-ups.

04

Data Analysis

Scaffold full analysis workspaces or answer one CSV with read-only SQL.

$dia-analyze-local-data

Create a local DuckDB workspace for one CSV and answer questions with read-only SQL.

$dia-new-data-analysis-workspace

Scaffold a fresh local data-analysis workspace with raw inputs, numbered pipeline scripts, and dashboard-ready output.

Roadmap

Planned skill groups that will complete the analytics spine. Each follows the same dia- naming convention.

Discover & Scope Planned

Frame the question, lock metrics, find the data, and scope effort before any query runs.

Main Flow Planned

Build the dataset, validate it, analyze, visualize, and write the narrative, in order.

Deep Dives Planned

Drill down on surprising numbers and investigate anomalies with structured evidence trails.

Data Operations Planned

Map lineage, document datasets, run QA checklists, and draft access requests.

Collaboration Planned

Stakeholder interviews, handoff packaging, plain-English rewrites, and briefing prep.

Reference Skills Planned

The metric glossary, chart choice, SQL style, and Python style every other skill cites.

Project Management Planned

Expand today's ritual loop with status reports, decision logs, and roadmap checks.

What's new

The library is versioned like any other campus artifact.

  • v1.1 Oct 2026

    Data analysis workspace scaffold

    $dia-new-data-analysis-workspace creates a fresh local workspace with immutable raw inputs, numbered pipeline scripts, a dependency manifest, and a dashboard-ready output layer.

  • v1.0 Oct 2026

    DIA naming convention

    The dia- prefix became the library standard: five skills were renamed and three new transcript skills were added for meeting notes, requirements, and process maps. Playbooks were introduced as ordered sequences in the repository.

  • v1.2 Planned

    Analysis spine skills

    Dataset building, data validation, and visualization as the first Main Flow skills.
