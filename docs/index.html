What is a skill?

A small, sharp instruction your agent runs the same way every time: connecting ClickUp, validating a project folder, writing a daily brief.

What is a playbook?

A curated sequence of skills for an end-to-end workflow. Pipelines hand off in one direction; fan-outs branch one shared input into several outputs.

Why it compounds

Every skill lives in one reviewed repository. Tuning one step improves every workflow that runs through it.

Playbooks

A playbook is a confirmed sequence of skills - you invoke one command and the steps run in order.

Reviewed skills strung into end-to-end workflows. One fan-out branches from a shared input; the pipelines hand off in one direction. The dot beside each playbook title shows the playbook's lifecycle; the dot beside every skill shows that skill's lifecycle.

Production = ready for daily use Testing = pilot-ready, may change Development = in progress

Fan-outs Fan-out one shared input, several independent outputs

One transcript, many artifacts

Save one Zoom transcript, then pull whichever derived documents the meeting needs. Each branch runs on its own and asks its own confirmation.
