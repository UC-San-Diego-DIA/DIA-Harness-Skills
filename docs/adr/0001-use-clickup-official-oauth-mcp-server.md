# Use ClickUp's official OAuth MCP server

The ClickUp connection skill will configure [ClickUp's official remote MCP server](https://developer.clickup.com/docs/connect-an-ai-assistant-to-clickups-mcp-server) directly over Streamable HTTP and authenticate each staff member through OAuth. [Codex supports this transport and OAuth](https://learn.chatgpt.com/docs/extend/mcp?surface=cli), so the connection needs no plaintext personal API token, Node.js, or third-party transport wrapper. New logins use the managed Codex runtime's automatic client-registration mode. This keeps the command compatible with TritonAI Harness's managed Codex 0.146.0 runtime, which supports MCP OAuth login but not the newer `--oauth-client-registration` selector. A working stored OAuth connection is verified before the skill considers reauthorization.

The team accepts ClickUp's public-beta status. The skill uses the TritonAI-managed Codex executable and Harness-owned `CODEX_HOME`; it does not substitute a global Codex installation. The skill will not migrate or fall back to a community server; if another server already owns the `clickup` configuration name, the skill stops and reports the conflict. OAuth issuer-validation failures are hard stops because bypassing issuer validation would weaken the authorization flow. The skill preserves the official configuration, records non-sensitive client versions for support, and does not repeat the same login within one invocation.
