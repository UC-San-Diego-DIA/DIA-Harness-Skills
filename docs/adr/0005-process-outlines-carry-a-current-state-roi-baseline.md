# Process outlines carry a current-state ROI baseline

A process outline needs more than an ordered flow to support a future-state comparison. The process-map skill now treats the current state as the baseline: touch effort per instance, elapsed or wait time, handoffs, error or rework rate, frequency or volume, source, and confidence. It also keeps each distinct process separate because a request-discovery workflow and the operational process a request targets can have different owners, volumes, and baselines.

Missing evidence is still evidence: the outline names it as a gap, records the evidence needed and collection method, and assigns an owner rather than leaving a blank cell or inventing an estimate. The user may accept a named gap explicitly, but the baseline is not complete while cells are silently empty. Future-state values remain optional and labeled, and a delta is calculated only when the current baseline and future-state values make the arithmetic explicit.

This keeps the skill focused on capturing a verifiable process baseline. It does not ask the skill to approve a project, produce requirements, or assert financial benefits the transcript does not support.
